# Pé da Serra Minimercado

Site institucional estático do Pé da Serra, implementado a partir do Figma aprovado. HTML, CSS e JavaScript sem dependências de build. Imagens, ícones e fontes locais.

Domínio: https://pedaserraminimercado.com/

## Publicação

GitHub Pages: branch `main`, pasta `/ (root)`. O arquivo `CNAME` mantém o domínio personalizado. Ativar HTTPS após a emissão do certificado.

## Manutenção

- Conteúdo e destinos: `index.html`.
- Layout responsivo: `styles.css`.
- Menu móvel: `site.js`.
- Imagens, ícones e fontes: `assets/`.
- Sitemap: `sitemap.xml`.

O site não recebe pagamentos, não armazena dados de visitantes e não envia mensagens automaticamente. Os links de WhatsApp, Google Maps e Instagram abrem os respectivos serviços.

Dados operacionais: São Bento do Sapucaí/SP; todos os dias, 7h–19h; WhatsApp (12) 99688-1212. O rodapé incorreto do protótipo foi alinhado aos dados confirmados e à seção de localização.
